# AD Project Hub V1 产品宪法

正式定位：面向广告/营销公司的 AI Project Operating System。北极星：人负责做业务，AI 负责把业务变成系统数据、流程、报告和经营建议。

## 不可轻易改变的原则

1. **Human by Exception**：默认系统与 AI 自动处理；仅在冲突、低置信度、资金确认、权限变化、高风险、商业判断、管理决策或 AI 无法可靠判断时找人。
2. **Minimum Human Touch**：能由规则或 AI 完成就自动完成；必须人工时优先选择/确认，不重复填表。
3. **Single Input, Multiple Effects**：业务事实只输入/确认一次，相关项目、财务、经营视图自动同步。
4. **Facts → Rules → AI**：事实是确定数据，规则是确定计算，AI 负责理解、分类、总结、异常、预测与建议；推断不得静默成为事实。
5. **Money Changes Through Confirmed Financial Events**：具业务效力的金额确认必须产生 Financial Event，并同步现金、应收/应付、项目与经营事实。
6. **Confirmed Financial Facts Are Not Silently Edited**：错误以 correction、reversal 或 new event 修正，保留审计链。
7. **One Truth, Different Views**：Role + Scope + Responsibility 决定视角，不复制多套真相。
8. **Exception First**：正常事项降噪，异常优先呈现。
9. **Next Best Action**：每个重要对象明确下一步。
10. **AI Is an Action Layer**：AI 是统一操作入口，理解意图并选择 Business Tool。
11. **AI Executes Through Tools**：AI Intent → Business Tool → Permission Check → Rule Check → Execute → Audit。
12. **Automation Risk Levels**：L0 Manual；L1 AI Assist；L2 AI Execute + Human Confirm；L3 AI Execute + Exception Review；L4 Full Automation。
13. **AI Must Explain Why**：重要判断必须给出依据。
14. **Business Memory ≠ Chat Memory**：长期记忆分类为 Fact、Pattern、Hypothesis、Decision。
15. **Audience Boundary**：内容明确区分 Internal、Client、Management，禁止内部经营信息泄露到客户版本。
